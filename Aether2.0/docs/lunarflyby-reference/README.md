# Referencia LunarFlybyOrekit

Esta carpeta conserva archivos del proyecto de consola `LunarFlybyOrekit.rar` como evidencia y referencia tecnica.

- `mission-data-sample.csv`: salida CSV generada por la simulacion de consola.
- `salida-lunarflyby.txt`: log completo de ejecucion Maven/Orekit del proyecto original.
- `pom-lunarflyby.xml`: configuracion Maven original, guardada solo como referencia.

La aplicacion AETHER principal usa Gradle, JavaFX, MySQL y las clases del paquete `com.example.demoaether`.
No se reemplazo el proyecto actual con el codigo de consola porque la version de AETHER ya contiene una integracion
mas completa con interfaz, persistencia, reportes y propagacion Orekit.
